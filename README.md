# T01(a) Appliance Energy Consumption Website

## COS30045 Data Visualisation

This project is a small interactive website demonstrating appliance energy consumption in the Australian market.

The website was developed using:

* HTML
* CSS
* JavaScript
* GitHub
* Vercel

## Website Pages

The website contains three main pages:

1. Home
2. Televisions
3. About Us

The navigation is implemented using JavaScript. The power logo returns the user to the Home page.

## Features

* Three-page single-page website
* JavaScript page navigation
* Active navigation-page feedback
* Mouse-over navigation feedback
* Power logo navigation
* Responsive CSS layout
* Television energy-consumption information
* Interactive television energy calculator
* Automatic copyright year
* Footer with GenAI acknowledgement

## Energy Calculator

The television calculator estimates electricity consumption using:

```text
Energy consumption (kWh) = Power (kW) × Operating time (hours)
```

The calculator also provides an estimated yearly consumption using 365 days.

The television values used in this demonstration are placeholder values and are not intended to represent current product specifications.

## Australian Market Context

The website provides general placeholder content related to household appliance electricity consumption in Australia. The project is intended as a demonstration of web development and interactive data presentation rather than as a source of current appliance specifications.
